# Nandish Thaker Portfolio

This folder contains a standalone recruiter/client-facing portfolio website for Nandish Thaker.

## Files

- `index.html` - Complete portfolio website with embedded CSS and JavaScript. It can be opened directly in a browser.
- `README.md` - Usage notes and source-grounding summary.

## Source Basis

The website was built from the provided resume PDFs, LinkedIn profile PDF, and Notion portfolio/case-study source.

The final version uses these clarified facts:

- NFL Draft traffic uses the Notion-backed sessions path: `108K monthly sessions -> 250K season-start sessions -> 550K peak sessions`.
- Mercor dates: `Nov 2025 - Mar 2026`.
- micro1 dates: `Nov 2025 - May 2026`.
- Contact email: `nandishthaker.work@gmail.com`.
- Only two full case studies are included: NFL Draft Content Strategy and Jhakaas Awards 2018.

## Editorial Choices

The portfolio is intentionally framed around increasing scope and leverage rather than personal work volume. It highlights:

- What Nandish owned.
- What decisions he made.
- What systems he built.
- How he influenced teams.
- How he allocated resources.
- How he solved business problems.
- How outcomes were measured.
- How the work affected growth, revenue, efficiency, and audience engagement.

## Evidence Rules

The site distinguishes verified metrics from qualitative claims and avoids misleading mixed-unit charts. Metrics such as sessions, revenue, votes, reach, tweets, team size, and page count are shown separately or clearly labeled.

The conflicting resume shorthand around NFL Draft traffic, `70%` versus `250%`, is not used. The site uses the clarified Notion-backed sessions path instead.

## How To Use

Open `index.html` in any modern browser. No build tools, hosting setup, external libraries, or deployment steps are required.

If editing the site later, keep the portfolio evidence-led:

- Do not add unsourced metrics.
- Do not convert the NFL traffic path into a single percentage unless the baseline and calculation are explicitly documented.
- Keep Mercor and micro1 dates aligned with the clarified record.
- Keep case-study visuals limited to comparable units.
